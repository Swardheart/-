# 快递选址与路径实验台

这个实验台把校赛论文里的快递代理点选址、单人最短回路、双人派送和同时取派算出来，在浏览器里和论文数字对照。

数据是 20 个小区的坐标、派件量和收件量，坐标单位是 km。距离用欧氏距离。页面打开时不再现算：`npm test`、`npm run dev` 和 `npm run build` 会先跑 `scripts/compute.ts`，把结果写进 `src/generated/results.json`。

## 和论文的对应

- 选址。每个小区都可以做代理点。小区 i 的权重是 wᵢ = α × 派件ᵢ + β × 收件ᵢ。选 j 的加权成本是 Σ wᵢ d(i, j)。平均加权距离 = 成本 / Σ w。最大服务距离是到其他小区的最远距离，不计本点。
- 单人路线。20 个点的闭合最短回路，用 Held-Karp 求最优。论文给出的方向和它的反向长度相同。
- 双人派送。代理点固定为 R，R 不进入访问序列。其余 19 个小区分成两组，每组路线是「R + 该组」的最短闭合回路。能力只限制一组的派件之和。
- 同时取派。从 R 出发时装上该组全部派件。每到一个小区，载件 = 当前 − 该点派件 + 该点收件。最大载件是沿途峰值，含出发时的载量。峰值超过能力时换一组。
- 权重灵敏度。五个预设都在页面上，最优代理点都是 R。

两个距离例题也写在页脚：A–B = 18.384776310850235 km，R–Q = 18.060177186284744 km。

## 五个结论

1. 派收同权时，最优代理点是 R。加权成本 20551.115631，平均距离 27.884824465288442 km，最大距离 61.595860250507094 km。第二名是 S，成本 21085.231966703253。
2. 另外四种权重的最优仍是 R。派件优先（α 1.2，β 0.8）成本 20615.513403；收件优先（α 0.8，β 1.2）成本 20486.717858；只看派件成本 10436.552247；只看收件成本 10114.563384。
3. 单人最短回路长 337.6263390235943 km，论文约写成 337.63 km。
4. 双人只看派件：能力 195 和 200 的总长是 352.45 km；能力 190 和 186 装不下派件 192 的那一组，总长改为 353.31 km。
5. 同时取派时，能力 186、190、195、200 都用总长 353.31 km 的分组。两名快递员的峰值是 177 和 186，调整后最大载件是 186。

## 安装和测试

需要 Node.js 22。

```bash
npm install
npm test
npm run dev
```

`npm test` 用 node:test 核对上面的选址、回路、分组、派件、收件、路线长度和最大载件，绝对误差小于 0.02。`npm run dev` 会先重新计算，再在本地打开页面。

构建静态页面：

```bash
npm run build
npm run preview
```

页面有四个视图：选址排名、单人路线、双人派送、同时取派。选址视图可以切换五种权重。双人派送和同时取派可以切换能力 186、190、195、200。每个关键数字旁边都写着「论文」和「本次」。
